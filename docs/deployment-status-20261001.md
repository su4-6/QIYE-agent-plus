JVM 与静态服务原资源回退文件仍在 本地 `server-slimming/rollback/` 交付目录；应只针对上述实际调整的服务使用，先核对现状。K3s 的软内存控制如需回退，先核对上述独有文件内容，再移除该文件并重新加载服务。交付不自动执行回退。
