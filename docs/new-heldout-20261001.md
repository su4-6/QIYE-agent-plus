# 新预留集、多信号判断与句子ID协议实测（2026-10-01）

本轮基于b8dcbf3改造，代码由Codex辅助实现。原始实验不覆盖：20261001是旧混合实验及30次MiMo；20261001-review是默认向量与严格字符串校验；本轮为20261001-heldout。当前项目仍为个人模拟IT服务台，尚未公开部署。

## 1. 修复0/27的协议冲突

旧流程让模型写自由文本，随后要求每句精确等于原文，导致27条引用合法的旧答复全部拒绝，其中17条核心有支持。这不是可用的改写校验。保留历史0/27记录，不把它改成新协议成绩。

当前模型只返回selected_sentence_ids，服务端从本次候选句子的白名单中读取原文组装答案，并自动得到引用、版本和chunk_key。模型附带的自由answer字段不进入用户答复。未知ID、非字符串、空列表或超过8条均不展示自动答案；租户及文档版本在请求前后再次校验。高风险和未通过证据发布门槛时仍走人工分支。

这解决了模型改写与严格字符串匹配的冲突，也限制了资料之外的时间和操作文本进入答复；**没有实现NLI或语义蕴含**，无法保证选中的原句适合当前场景。

用户明确追加授权最多10次MiMo调用、输出最多10000 tokens、关闭重试。固定5条旧失败样本＋5条新题做协议压力验证，不从结果中挑成功样本；不是随机企业工单样本。隔离数据库直接调用生成器，未绕过应用发布保护给用户自动答案。

9/10表示组装成功，**不是90%语义正确率**。AI逐条对照问题与来源：6条核心匹配、2条来源范围过宽、1条显示器问题误选投影资料、1条询问账户等待时间时弃答。严格主题标签是模拟代理判据，AI审查也不是人工金标准。边界／场景失败仍保留；资料正确引用不等于建议正确。原30次与新10次总共40次调用，输出合计4501 tokens，两份预算账本分别保留。

## 2. 模型冻结后才建立新60题

1. 只用原180条用例的calibration部分：90条中排除15条高风险，剩75条训练。原test部分和后续30条知识外挑战均不用于拟合或选阈值。
2. 收集8信号：首条词覆盖、首条向量相似度、向量首／次差、BM25首／次相对差、两通道首位一致、前三交集、词法有结果、向量有结果。影子BM25只提供实验信号，不改变纯向量排序。模型特征没有文档主题ID或预期标签。
3. 固定L2逻辑回归、零初始化、3000步、学习率0.1、正则0.05；五折按主题／负例group分组。阈值只扫描out-of-fold评分，要求放行精确率≥95%且至少20条，再选最大覆盖。OOF为50/52=96.15%，阈值0.680712491；随后只在这75条上拟合最终权重。
4. 保存模型、权重、阈值、输入及特征源码摘要：2026-10-01T05:08:48.987518+00:00。保存新问题文件：2026-10-01T05:11:06.204890+00:00。新题文件绑定该模型SHA，测试脚本禁止修改特征代码、重新拟合或覆盖已消费的测试记录。
5. 新60题是40条可回答（20个偶数主题，每主题两种新表达）、10条知识外、10条高风险；可回答主题与原训练／校准的奇数主题不交叉，问句与原数据无完全重复。标签由AI按SOP范围生成，没有人工双人标注。

新题没有参与本次拟合、模式选择、阈值或规则调整，评测后未再调参。语料仍是已知60段模拟SOP，出题者知道旧实验和主题；这是冻结模型上的新预留集，不是未知企业工单、未见领域评测或独立第三方盲测。

## 3. 多信号有收益，仍没达到发布门槛

| 同一新60题 | 单评分冻结阈值 | 8信号逻辑回归 |
|---|---:|---:|
| 允许建议的来源主题正确数／放行数 | 35/46 | 29/31 |
| 放行判断精确率 | 76.09% | 93.55% |
| 误放行 | 11 | 2 |
| 实验放行覆盖率 | 76.67% | 51.67% |
| 人工混淆矩阵TP／FP／TN／FN | 14／0／35／11 | 23／6／29／2 |
| 发布门槛 | 不通过 | 不通过 |

正标签是“问题可回答且首来源主题正确”，不是模型答案语义正确。高风险始终优先转人工。逻辑回归输出是用于实验排序与阈值选择的判别分数，没有校准成真实答案正确概率。

剩余误放行是“摄像头已恢复，询问培训费用”和“磁盘清理完成，询问设备折旧”：IT词汇主导召回，但实际诉求已经切换到非IT制度。保留这2条，不用新题调出漂亮门槛。逻辑回归目前仅为离线实验；默认线上证据策略未切换，也没有打开自动建议发布保护。

新40条可回答题的向量Hit@3为38/40=95%，它与原60条可回答测试查询的56/60=93.33%是不同分母，分开报告。也不能将Hit@3当成自动放行精确率或答案正确率。
