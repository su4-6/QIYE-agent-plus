# 简历描述与证据边界

> 本文主体是早期检索实验的表达与数字边界，不是项目启动说明。后续已经公开部署，并新增员工多轮辅助、规则审批与模型切换，见 [README](../README.md) 和 [部署历史](deployment-status-20261001.md)。旧测试数量与句子 ID 协议描述对应实验版本，不用于概括全部当前能力。

项目名：Atlas Desk · 智能工单处理 Agent（个人项目，AI辅助实现）

技术：FastAPI、LangGraph、SQLite FTS5、sqlite-vec、BGE中文向量、RRF、MiMo、Docker/K3s部署配置。

可复制的三条描述：

- 搭建基于 LangGraph 的工单分诊与 RAG 处理流程，采用BGE中文向量优先检索、FTS5 BM25故障降级，并保留RRF混合对照与来源追踪；建立60段模拟SOP、180条固定查询的分组评测，在原180条用例中的60条可回答测试查询上将旧关键词算法 Hit@3 从40%提升至93.33%（同语料对照，提升53.33个百分点）。
- 完善访客凭证、租户过滤、管理员审批与事务审计，补充45项自动化测试覆盖跨租户访问、引用版本校验、向量失败恢复、并发审批、备份恢复与重启；本地关闭LLM，在并发1／5／10下完成300/300次“提交＋凭证查询”工作流。
- 建立检索健康监控、请求追踪和评测驱动的人工接管机制；使用8项检索信号训练逻辑回归并按主题分组做交叉验证，在模型冻结后新增的60条模拟测试题上，将放行判断精确率从76.09%提高到93.55%，误放行从11条降至2条；未通过95%门槛，保留人工审核，分类器作为离线实验。

## 每条数字怎么回答

| 数字 | 怎么测 | 测到的是什么 | 限制 |
|---|---|---|---|
| 60段／180问 | 固定JSON语料与查询；90校准、90测试，主题分组 | 模拟知识覆盖与实验规模 | AI辅助生成标签，没有人工双人标注 |
| 旧关键词Hit@3 40% | 原180条用例的60条可回答测试查询、同一60段语料 | 24/60命中前三个相关主题 | 冻结关键词基线；非答案正确率 |
| 纯向量Hit@3 93.33% | 与上一行完全相同的语料与查询 | 56/60；对旧关键词提升53.33个百分点 | 原测试集对照；非新增60题的成绩 |
| 混合Hit@3 86.67% | 与上两行同一实验，方法为RRF＋业务重排 | 52/60 | 混合实验配置，当前默认为纯向量 |
| 45测试 | unittest discover；原始输出随结果保存 | 45个明确工程场景通过 | 不等于100%代码覆盖，也不等于抵御所有攻击 |
| 300/300 | 20261001-review目录，实际HTTP，并发1／5／10各100个工作流 | 201创建与凭证查询一致性 | 先前版本测量，LLM关闭，短时本地运行；本次未重跑压测 |
| 76.09%→93.55% | 新60题，比较冻结单评分阈值与8信号逻辑回归 | 35/46→29/31被放行的来源主题正确，误放行11→2 | 覆盖率76.67%→51.67%；AI模拟标签，非答案正确率；未达95%，未默认接入 |
| 新题Hit@3 95% | 新60题中的40条可回答问题，原语料不变 | 38/40命中 | 新预留集，与原60条可回答测试查询分开报告 |
| 新协议10次／9次 | 经追加授权最多10次MiMo，句子ID由服务端校验并组装原文 | 10/10结构化，9/10组装成功，177输出tokens | 挑选的压力样本，严格主题匹配6/10；不能称语义正确率90% |
| 30次／27次 | 实际MiMo调用、记录原文和使用量 | 27/30输出引用非空且可追溯，3次被拒绝 | 不等于27条答案语义正确；AI审查发现10条未支持细节 |

当前生成协议采用句子ID选择，由服务端读取并组装原文；模型自由文字不进入答复。历史0/27是旧严格原句匹配的回放结果，不改写为新协议成绩。新协议10次实测仍有选错或多选场景，人工审核继续保留，没有实现NLI。

## 面试里的关键取舍

“我没有把置信度当成模型自报的正确概率，而是把证据信号变成可复现分数，在校准集选阈值，再看独立测试集。校准达到95%，但测试未达到，我保留了这个失败结果，默认转人工，没有在测试集上反复调参。”

“混合不一定优于单路向量。我做的消融中，标题加权有负收益，说明通用词和制度边界会引入排序噪声。下一轮需要新的独立验证数据再调整融合策略。”

“服务端验证引用、租户与版本，再让模型选择句子ID，由服务端从原文组装答复，限制新增企业规则或操作。这个协议避开了模型改写与精确字符串匹配的冲突，也不能保证资料本身正确、与问题相关，因此应用仍保留人工审核。”
