# 本轮改动记录（2026-10-01）

需求由用户提出并确认，Codex辅助完成实现、实测与文档整理。改动基于分支 codex/atlas-desk-rag 的 f869404；本轮提交ID以Git记录为准。

| 改造 | 原问题 | 当前行为 | 证据 |
|---|---|---|---|
| 向量故障治理 | 异常吞掉、配置等同就绪 | 覆盖率、维度、模型版本、扩展与最近运行状态；未验证状态明确上报 | 故障注入、恢复及健康检查测试 |
| 引用一致性 | 第四条资料可能被引用却未返回；非法ID被过滤后仍接受 | 四条上下文与引用集合一致；任意非法ID、错误租户或旧版本整次拒绝 | 引用、版本及第四条返回测试 |
| 检索整理 | 运行检索与旧关键词实现容易混淆 | 旧算法只在evaluation中作为冻结基线；在线模块统一 | 同语料七组对照 |
| 知识与分块 | 六段资料、字符硬切 | 60主题模拟SOP；完整句与标题路径、稳定段落标识 | 导入、版本、分块测试与显式导入脚本 |
| 评分与审批 | 人为置信度公式、未实测的边界 | 单一证据分数，校准后冻结；独立测试不过门槛则人工审核 | 阈值实验与发布门槛测试 |
| 可观测性 | 无统计、无请求关联 | 管理员租户统计、历史缺字段单列；请求ID与结构化日志 | API、追踪和浏览器验证 |
| 持久化运维 | 限流桶永不清理，迁移备份缺失 | 绝对过期时间、正确小时／日迁移、在线备份与重复启动 | 旧库、恢复、并发审批测试 |
| 量化证据 | 容易混用不同语料和模拟向量数字 | 真实512维BGE、隔离数据库、固定标签、原始结果与SHA清单 | results/20261001 |
| 模型实验 | 无限重试或中断后重复请求风险 | 30次预算账本、每次1000输出tokens、无自动重试、结果复用 | generation-ledger与30条原始结果 |
| 模型请求边界 | 仅在生成后检查引用可能让错误租户资料发出 | 请求前校验全部上下文；错误租户在调用SDK前拒绝 | 离线故障注入测试；不追加真实调用 |
| 容器资源 | 空PVC遮住镜像data目录；镜像缺少发布策略 | 静态语料独立resources路径，打包冻结策略 | 空数据卷路径测试；未实际构建镜像 |
