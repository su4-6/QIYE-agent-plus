# 员工自助支持：电脑蓝屏

电脑出现蓝屏或停止错误时，先确认自动重启后是否能进入桌面，记录停止代码和发生频率，不能仅凭“蓝屏”确定故障原因。
如果电脑已经重启并恢复正常使用，先保存工作并观察是否再次出现，不要把一次蓝屏直接认定为设备损坏。
如果故障发生前刚接入新的外接设备，可以在关机后移除该外接设备，再观察启动情况；不要拆开机箱。
如能正常进入桌面，可以查看系统盘剩余空间是否充足；不要为腾空间删除不认识的系统文件。
反复出现相同停止代码或无法进入桌面时，应联系 IT，并提供停止代码、出现时间与近期变化。
驱动卸载、系统还原和企业软件变更由 IT 按授权处理，员工不自行执行。

参考：Microsoft Support 的 Windows unexpected restarts and stop code errors。上述内容为演示场景整理，不代表企业制度。
