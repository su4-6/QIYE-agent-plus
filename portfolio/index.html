01关于我 / About

从具体问题出发，理解代码与系统

关注方向

  • Java 后端开发
  • 事务与消息协作
  • 知识检索与 Agent
  • 接口与异常处理
  • Linux 与容器部署

我是一名软件工程本科生，正在寻找第一份实习。Java 后端是目前的学习主线，AI 应用与 Agent 是希望继续深入的方向。比起只记住框架名称，我更希望说清楚一个功能为什么这样实现、会在哪里失败。

学习时，我会沿着一条具体链路读代码：请求由谁接收，哪些模块参与，数据在哪里写入，异常怎样返回。再通过调试、测试和运行记录检查自己的理解，遇到问题先定位原因，再调整实现。

项目让我有机会把这些问题放在一起练习。MiniPay 聚焦支付与钱包的业务链路；Atlas Desk 聚焦检索、引用与人工接管。我也在实践部署和排查，让项目从本地代码走到可访问的演示环境。
